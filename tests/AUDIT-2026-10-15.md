## 자동 검사 범위

- 최초 로컬 기록 이전, ID 중복 방지, 삭제 기록의 재유입 방지, 저장소 차단, SDK 누락, 시작 통신 오류.
- 잘못된 날짜/금액/저장 데이터, HTML 속성 삽입 방지, 음수 입력, 안전한 정수 범위 밖 입력 거절.
- 무작위 사다리 10,000회: 3명씩 배정, 혜빈·민경 반대 팀, 실제 경로와 결과 일치. 가능한 12가지 팀 배정 × 2가지 승리 결과 전부의 개인 전적 확인.
- 연타 및 동시 팀 배정, 취소와 승리 저장 경합, 서로 다른 승리팀 저장 경합, 이전 경기의 선택이 새 경기에 적용되지 않는지 확인.
- 개인 누적 금액, 조합/시너지 및 개인 승률, 최근 5경기와 이전 기록, 회차 연결.
- 3천원/5천원 전환, 정산 100회 연타, 지연 응답 중 추가 입력, 저장 실패/재시도/응답 유실, 새로고침 복구, 여러 탭의 미저장 입력.
- 정산 판 저장 중복 방지, 다른 화면에서 먼저 기록한 판으로 뒤늦은 입력 전달, 초기화한 세션에 이전 클릭이 들어가지 않는지 확인.
- 기록 삭제/초기화 실패와 취소, 초기화 범위, 기본 1~8회차 보존.
- Realtime 갱신 경로 및 통신 오류 이후 재조회 복구. 10초 주기 조회와 화면 재진입 갱신 코드는 유지.
- 1,000개 일반 경기 + 1,000개 3:3 경기 통계를 별도 계산과 대조. 충돌 확인 URL에는 전체 경기 JSON 대신 숫자 revision만 사용함을 검사.

## 브라우저에서 확인한 사항

- 의도적으로 저장 후 응답만 실패시키고, 새로고침 후 같은 입력을 다시 저장: 총 경기 수가 한 번만 증가하고 입력창 정상 정리.
- 느린 개인 경기 저장 도중 입력 변경: 이전 값은 기록에 저장되고 새 값은 입력창에 보존.
- 두 화면 사이 정산 자동 반영, 펼쳐 둔 날짜 기록 유지.
- 모바일 정산 저장 실패 안내와 '다시 저장', 금액 보존, 판 기록, 초기화 '아니오/예'.
- 3:3 배정/승리 저장/취소/삭제 '아니오/예', WIN 표시 및 통계 반영.
- 확인창의 초기 초점, Shift+Tab, Esc, 초점 복귀.
- 많은 기록 상태에서 모바일 음수 입력, 추가 저장, 회차 표시, 16px 입력 글꼴 및 가로 넘침 확인.

## 검증의 한계

모든 브라우저 버전·실제 휴대폰·통신 장애의 조합을 전부 증명한 것은 아니다. 모바일 검사는 브라우저 화면 크기를 바꾼 검사이며 실제 iOS Safari/Android 키보드 테스트는 포함하지 않는다. 1,000경기 검사는 가상 데이터로 기능과 표시를 확인한 것이며 장기 운영 부하나 서버 용량 보장은 아니다. 운영 서버는 읽기와 배포 확인만 하므로 실제 서비스 장애를 발생시키는 시험은 하지 않는다.

현재 공용 입력 구조를 로그인 구조로 바꾸거나 데이터베이스를 경기별 테이블로 분리하는 작업은 이번 오류 수정에 포함하지 않는다. 추가 기능은 사용자에게 제안만 한다.
