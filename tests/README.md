# 사이트 회귀 검사

저장소 루트에서 `node tests/audit.cjs`를 실행합니다. Node.js 기본 기능만 사용하며 별도 패키지는 필요하지 않습니다.

실제 Supabase나 GitHub Pages에는 요청하지 않습니다. 메모리 안의 가짜 서버에서 마이그레이션, 저장 충돌, 서버 오류, 사다리 배정, 통계, 정산, 삭제, 초기화를 검사합니다.

정산 검사는 연속 클릭의 즉시 반영과 일괄 저장, 느린 응답 중 추가 입력, 저장 실패·재시도, 응답 유실 후 중복 방지, 새로고침 후 미저장 입력 복구, 여러 화면의 판 기록 충돌, 정산만 초기화하는 범위까지 포함합니다.

이 검사는 실제 휴대폰 키보드, 네트워크 속도, Supabase 서비스 가용성까지 보장하지 않습니다. 화면 수정 시에는 별도로 PC·모바일 너비에서 확인합니다.
